# Restaurant-Feedback Management System

A simple and interactive **feedback management web application** built using **HTML, CSS, and JavaScript**.
This project allows users to submit feedback, store it in the browser using localStorage, and view it dynamically with a clean UI.


---

##  Features

* User-friendly feedback form
* Stores feedback using **localStorage** (no backend required)
* Dynamically displays submitted feedback
* Modal popup to view full user details
* Delete feedback functionality
* Form validation (required fields)
* Responsive design for different screen sizes
* Persistent data even after page reload

---

##  Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & Layout
* **JavaScript (Vanilla JS)** – Logic, DOM manipulation, localStorage

## How It Works

1. User fills out the feedback form
2. Data is stored in **localStorage**
3. Feedback entries are dynamically displayed on the page
4. Clicking **"About Me"** opens a modal with full details
5. Users can delete feedback entries
6. Data persists even after refreshing the page
