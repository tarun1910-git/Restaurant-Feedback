# 🍽️ Urban Bistro – Feedback Web App

A modern, responsive restaurant website with an interactive feedback system built using **HTML, CSS, and JavaScript**.

---

##  Features

*  Customer feedback form
*  Star rating system (1–5)
*  Profile image upload
*  Edit feedback
*  Delete feedback
*  View feedback in modal popup
*  Data stored using LocalStorage
*  Responsive design
* Clean UI with glassmorphism & overlay effects

---

##  Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

##  Project Structure


Urban-Bistro/
│── index.html
│── style.css
│── script.js
│── images/



##  How It Works

* Users can submit feedback with name, email, rating, and message
* Feedback is stored in **browser LocalStorage**
* All entries are displayed as dynamic cards
* Users can:

  * View details (modal popup)
  * Edit existing feedback
  * Delete feedback
